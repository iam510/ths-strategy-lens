# 扶摇真实数据验收

时间：2026-10-30（Asia/Shanghai）。范围：本地应用；首次验收时模型及托管密钥尚未配置。后续本地模型已验证，见[模型接入验收](./模型接入验收.md)。

## 实际结果

- 用户自行取得并在本地填写扶摇 API Key；密钥未显示在输出中、未上传到托管平台。
- 5 类接口实际鉴权成功：行情快照、指数成分、交易日历、年度利润表、前复权历史 K 线，HTTP 200 且业务 code=0。无敏感字段的记录见 [fuyao-contract-probe.json](../artifacts/fuyao-contract-probe.json)。
- 本地 `/api/screen` 使用真实模式成功：沪深 300 当前成分共 300 只，按代码升序评估前 12 只，数据截至 2026-10-30。
- 条件为年报营收同比 >5%、参考静态 PE ≤30、60 日年化波动率 ≤35%；结果为 6 入选、6 排除、0 无法判断。
- 有 3 个指标因亏损、非正基数或不适用而保留为 missing；这些样本同时存在明确失败条件，因此总体判为排除，并未将缺失当作满足。
- 对 API 快照中的 57 项有效指标，以原始字段独立复算同比、PE、波动与回撤，结果一致；并核对来源和 request_id。见 [live-data-verification.json](../artifacts/live-data-verification.json)。此验证证明取数和计算链路，不等同于独立审计数据商的财务真实性。

浏览器首次真实快照为 `live-09d40ecb-1fb2-4739-a4c5-60ca14fec12d`；同快照修改后结果为 3 入选、9 排除，3 个样本状态改变，页面展示对应条件和实际值。比较未再次取数，不混入行情刷新。

另检查了亏损样本：总体排除原因可见，同时 PE 显示无法判断，来源、年报披露日、行情日、请求编号均可查验。

原始响应和真实数据截图仅保存在本地 `artifacts/private/`，已加入忽略规则，并被提交打包脚本排除。公开源材料仅保留验证摘要，不附数据商原始金融数据包。未获得授权的公开再分发不在本轮范围。

## 实际修复

Node 直连接口正常，但最初 Worker 中报错：运行时不支持 `redirect: "error"`。已将扶摇和兼容模型的服务端请求改为 `redirect: "manual"`，非成功状态明确报错，不跟随重定向转发密钥。加入重定向回归用例后，51 项测试及类型检查通过。

工作台接入状态也改为在成功取得真实快照后显示“已获取真实快照”，避免已取数后仍显示“待实测”。
