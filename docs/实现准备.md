# 第一题实现准备

状态：初始需求拆解与建议，保留为规划记录。本文件的计划项不代表已验证结果；最新实际进度见[交付说明](./交付说明.md)，初始安排见[实施计划](./实施计划.md)。

## 1. 题目定位

用户要把“经营改善、估值合理、走势相对稳定”等模糊意图转换为可检查、可修改、可执行的条件，并用真实数据解释候选股票和排除原因。

第一版建议围绕一条闭环：输入意图 → 澄清关键歧义 → 确认条件 → 检查冲突 → 获取数据并确定性筛选 → 查看入选/排除证据 → 修改条件比较变化 → 保存策略。

后续操作先实现“比较 + 保存策略”，满足题目所列比较、保存、回测或监控方向；回测和监控先列为未做事项，不展示无法实际使用的入口。

## 2. 职责边界

| 模块 | 负责 | 输出约束 |
| --- | --- | --- |
| AI 意图解释 | 提取意图、指出歧义、提出可修改条件、生成基于证据的说明 | 不生成行情/财务数值，不自行宣称筛选通过；输出经结构校验 |
| 确定性引擎 | 条件校验、范围冲突识别、字段比较、入选/排除/无法判断、条件版本差异 | 同一条件版本和数据快照必须得到一致结果 |
| 金融数据适配器 | 访问真实数据，标准化字段、时点、单位、来源、口径及失败状态 | 保留数据证据；缺失、过期和失败不得转换为零或正常值 |
| 产品界面 | 澄清、条件编辑、筛选、解释、比较与保存 | 明确区分 AI 建议条件、用户确认条件、事实和推断 |

## 3. 先验证数据能力，再固定筛选指标

原题参考入口：

- 扶摇：<https://fuyao.aicubes.cn/docs/>
- iFinD MCP：<https://mcp.51ifind.com/?syncCookieTimes=1>

已阅读 iFinD 官方入口的公开服务介绍；扶摇文档本次通过网页读取工具打开失败。访问权限、接口调用和实际字段仍未验证。进入实现阶段先核验实际可调用能力、授权方式、调用限制、可展示/保存范围、字段口径和时点；不得根据参考入口假定任何具体 API 可用。

优先探索一组覆盖经营、估值与稳定性的最小指标，但须以真实字段为准：

- 经营改善：例如收入或利润的同比变化；需明确报告期、是否累计口径及异常基数处理。
- 估值合理：例如 PE/PB 或其他已支持指标；需明确 TTM/静态等口径，不能把负 PE 直接解释为便宜。
- 走势稳定：例如指定窗口收益波动或最大回撤；需明确复权方式、交易日窗口、停牌与样本不足规则。

“合理”“稳定”没有统一阈值。界面可提供明确标注的建议值，但必须允许用户检查和修改，不把建议阈值写成客观事实。

若无真实接口权限，可用明确标注的构造数据开发逻辑和异常用例；真实数据主链路验收仍为未完成。离线真实快照仅在来源、日期及使用权限可核验时采用，并显式显示快照时点。

## 4. 建议数据契约

以下为内部建模建议，不是已验证的第三方字段名：

- 条件：字段、运算符、阈值、单位、统计窗口/报告期、口径、缺失处理、条件来源和版本。
- 数据证据：股票标识、原始字段和值、标准化值、来源/引用、数据时点、披露时间（适用时）、获取时间、单位、口径和有效状态。
- 筛选结果：入选/排除/无法判断、逐条件结论及证据引用、数据快照与条件版本。
- 条件比较：保持数据快照一致，对比修改前后新增、移除、仍入选和无法判断的股票，避免混入行情变化。

有任一条件明确失败时可判为排除，同时保留其他缺失项；无失败但存在缺失/失效项时判为无法判断；所有条件均满足才入选。

## 5. 建议技术起点与实现顺序

建议单个 TypeScript Web 应用，在服务端调用模型和数据工具，浏览器仅接收必要结果；具体框架、依赖版本与部署平台在初始化前核验后确定。密钥只放本地环境变量或部署平台密钥配置。

1. 核验真实金融数据与模型接入，形成字段映射和权限边界记录。
2. 初始化应用，先实现条件契约、证据契约和确定性筛选函数。
3. 为筛选、冲突、缺失值和口径边界编写有意义的单元测试。
4. 接入 AI 意图解析和澄清；不支持的条件明确提示，不静默忽略。
5. 完成条件编辑、真实数据筛选、入选/排除/无法判断解释。
6. 完成同快照条件比较、策略保存和重新载入。
7. 执行浏览器主链路及故障验证，补全真实 AI 使用记录与测试证据。
8. 完成仓库与部署，实际验证公网 URL；补全 README 和可选演示视频。

## 6. 验收重点

- 对模糊输入能识别歧义并得到用户可确认的条件；不存在未经提示就采用的关键假设。
- 如同一指标同时要求大于 20 且小于 10，应在执行前提示冲突并支持修改。
- 每只股票都有逐条件实际值、阈值、结论、来源、时点、单位和口径。
- 空结果可解释；字段缺失、过期、接口失败或样本不足均有可见状态。
- 条件修改后的结果变化可复算，保存策略可重新载入执行。
- 模型输出格式错误、虚构字段、提示注入和直接买卖请求不会绕过契约与确定性引擎。
- 不输出确定性涨跌预测、收益承诺或直接买卖建议。
- 公网产品可操作，部署后真实数据和模型调用可用；本地测试通过不等于完成部署验收。
