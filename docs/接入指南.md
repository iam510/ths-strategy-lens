# 数据与模型接入指南

以下均需使用你自己有权限的账户。本地扶摇已配置并通过真实接口和浏览器验收；MiniMax 本地真实解析与澄清也已通过验收。构造体验不能替代真实接入验收。

## 1. 扶摇金融数据

1. 打开[扶摇官网](https://fuyao.aicubes.cn/)，自行完成登录。
2. 进入[API Key 管理](https://fuyao.aicubes.cn/admin/)，创建具名密钥并妥善保存。若提示无权限、需开通或存在使用条款，按官方流程处理；项目不会代办账户、购买或绕过限制。
3. 将密钥填写到本地 `web/.env.local` 的 `FUYAO_API_KEY`。不要在聊天、代码、截图或公开仓库中粘贴密钥。
4. 确认可调用的能力至少覆盖：指数成分、交易日历、行情快照、年度利润表、前复权历史日 K。

官方说明：[快速开始](https://fuyao.aicubes.cn/docs/quickstart/)、[接口总览](https://fuyao.aicubes.cn/docs/api-reference/overview/)。使用 `X-api-key` 请求头，HTTP 200 不代表成功，必须检查业务 `code === 0`。

2026-10-30 的无密钥实测：行情快照接口返回 HTTP 200，响应 `code=2003`、`message=Missing X-api-key`、`data=null`。项目已按业务失败处理。文档与实测错误码可能不完全一致，因此不依赖 HTTP 状态或单一鉴权错误码判定成功。

本版优先接入扶摇；iFinD 作为后续扩展候选，尚未实现 iFinD 适配器。无需为本版同时购买或配置两种数据服务。公开展示与数据保存范围须遵循实际授权，代码不内置受限金融数据包。

## 2. 模型服务

实现使用 AI SDK 及其 OpenAI Compatible provider，需要支持 Chat Completions 和 JSON 对象输出的服务。模型名称不在代码中写死，须采用你的服务商当时支持的名称。

用户已选择 MiniMax，具体配置见[MiniMax 接入](./MiniMax接入.md)。四项本地配置已填写并实测，详见[模型接入验收](./模型接入验收.md)。托管 secrets 独立配置，本机文件不会自动同步。

填写三个值：

- `AI_BASE_URL`：服务商给出的 API 根地址，须为 HTTPS，不要填写完整的 `/chat/completions` 地址。
- `AI_API_KEY`：服务商密钥。
- `AI_MODEL`：服务商当前可用且支持上述能力的模型 ID。

如果使用其他兼容服务，按该服务官方文档配置。如果选择 OpenAI 且希望由 Codex 协助开通/获取密钥，应先启用 OpenAI Developers 插件，按其密钥工作流操作；无需在此处发送密钥。

## 3. 本地配置与验证

在提交目录内执行：

```sh
cd web
# 仅首次创建文件时执行；已有 .env.local 时不要覆盖\ncp -n .env.example .env.local
# 在你自己的编辑器里填写 .env.local
npm ci
npm run dev -- --port 5186
```

`.env.local` 已被忽略，不能放入提交包。修改后重启服务；页面右上角“已配置”只检查参数是否齐全，不能证明鉴权或接口成功。

验证顺序：

1. 页面右上角检查配置状态。
2. 点击“用 AI 拆解条件”，核对模型生成条件、澄清及不支持项。
3. 选择“真实数据”，核对条件并执行，展开真实股票证据，检查原始字段、来源、时点与 request_id。
4. 修改单个阈值，以同快照再次执行并复核变化。
5. 保存测试证据后，才将交付说明中的真实接入状态改为已验证。

## 4. 托管配置

本地密钥不会自动进入 Sites。拥有者需通过 Sites 运行时环境变量配置相同四个名称，密钥标记为 secret，再部署对应保存版本。不要把密钥写进 `.openai/hosting.json`。

发布成功只表示构建可访问；还需分别验证访问权限、托管网络到扶摇/模型的连通性、鉴权和真实主链路。当前预览保留为私人站点，不能直接当作招聘方可访问的提交 URL。
