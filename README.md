# 析选 · 自然语言智能选股与策略解释器

同花顺 AI 笔试的独立 Web 实现：自然语言意图 → 必要澄清 → 可编辑条件 → 冲突识别 → 真实筛选 → 证据 → 同快照比较 → 保存与载入。

- 产品：https://strategy-lens-ths-510.green-trout-2026.chatgpt.site/
- 评审方式：无需 ChatGPT 账号。点击“输入评审访问码”，使用投递材料中单独提供的访问码，解锁 AI 与真实金融数据。无访问码可操作明确标识的构造体验。
- 公开源码：https://github.com/iam510/ths-strategy-lens

## 本地运行

Node.js 22.13+ 与 npm：

```sh
npm ci
npm run dev -- --port 5186
```

打开服务打印的地址。没有凭据时点击“试用预设构造场景”，得到完整的虚构交互；不静默冒充真实数据。

如需自己的真实服务，复制 `.env.example` 为 `.env.local`，填写以下服务端配置。不要覆盖已有配置或提交自己的密钥。

| 变量 | 用途 |
| --- | --- |
| FUYAO_API_KEY | 自有扶摇数据密钥 |
| AI_BASE_URL | OpenAI 兼容 HTTPS 接口根地址 |
| AI_API_KEY | 自有模型密钥 |
| AI_MODEL | 模型 ID；本项目实测 MiniMax-M3.1-Flash |
| REVIEW_ACCESS_CODE | 可选评审访问码。留空为本地不设评审门槛；公开部署时配置为 secret |

托管配置通过 Sites 运行时 secrets 单独管理，不从本地 env 自动继承。若克隆后另行部署，需要注册自己有权限的 Site 并使用其项目 ID；仓库中原 Site ID 不授予部署管理权限。

## 职责与数据口径

- AI 仅将意图转为待确认条件和澄清；完整 JSON Schema、Zod、字段白名单、引用关系及输出边界校验，无效输出显式失败。
- 确定性引擎执行 AND 条件、识别无交集，返回入选/排除/无法判断。模型不生成行情数字或决定入选。
- 扶摇适配器提供原始字段、计算公式、时点、单位、来源与 request_id。原始真实响应不存入本公开仓库。
- 沪深 300 或上证 50 当前成分按代码升序，最多取 12 只样本，非全市场筛选。
- 财务采用最近两份连续年报同比，非正上年基数无法判断；参考静态 PE=最新价/年报基本 EPS，非 TTM、未处理年报后股本变化，非正 EPS 无法判断。
- 波动/回撤采用最近 61 个完整交易日的前复权收盘点；60 个对数收益、样本标准差乘 √252。16:00 北京时间前不使用当日未完成 K 线。
- 所有条件满足才入选；至少一项失败则排除，同时保留其他缺失项。无失败而存在未知则无法判断。

同快照条件比较限 15 分钟内真实快照，刷新重建基线。最多保存 20 条条件到当前浏览器；导出不含行情、评审码或接口密钥。不提供确定性涨跌预测、收益承诺或直接买卖建议。

## 验证

```sh
npm test
npm run typecheck
npm run build
```

62 项自动化测试：策略 27、数据适配器 14、AI/API 13、评审授权 8。单元模型与数据成功路径使用 mock；另有真实模型/数据 API 和实际浏览器验收记录，不能互相替代。

评审码校验在服务端覆盖 AI 与真实筛选接口；缺失/错误码返回 401，构造体验公开可用。访问码仅保存在当前标签页；运行时可换码撤销旧码。模型和数据密钥保留在服务端。输入长度、同源校验和实例内频率限制已实现，未声称具有分布式全局配额保护。

曾观察到托管到扶摇的间歇连接超时，成分与交易日历入口增加一次有限运输重试（750ms 间隔、每次 20 秒），HTTP/业务/结构错误不重试；无效结论不会伪造。修正后线上补验通过，长期稳定性、所有地区网络和供应商数据正确性未独立审计。
